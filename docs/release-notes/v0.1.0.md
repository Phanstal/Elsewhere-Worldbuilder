# Elsewhere v0.1.0

The first release of Elsewhere, a local-first worldbuilding studio for macOS.

## What's here

- **Spatial world canvas** — 14 node types across Space, Entities, Lore, and Media; pan, zoom, and Fit.
- **Relations** — drag from a node port to another node, then rename the relation inline or in the inspector.
- **Aliases** — show the same character or place in two parts of the map without duplicating it in the node count.
- **Create / Explore** — edit with the full sidebar and inspector, or step into a read-only reading view.
- **Local autosave** — SQLite on the desktop, with `Saving…` / `Saved` feedback and undo / redo.
- **`.elsew` import / export** — a readable, versioned JSON world format. Imports always create a new world.
- **PNG export** — the whole world at 2× through a native save dialog.
- **Native macOS shell** — overlay title bar, application menus, `⌘N`, `⌘S`, `⇧⌘E`, `⇧⌘P`, `⇧⌘O`, and window state restore.
- **Sample world** — [`samples/the-hollow-reach.elsew`](../../samples/the-hollow-reach.elsew) is the world in the screenshots.

## Install

Download `Elsewhere_0.1.0_universal.dmg` (Apple Silicon and Intel, macOS 12+) and drag `Elsewhere.app` to `/Applications`.

This build is **unsigned and not notarized**. On first launch:

1. Right-click `Elsewhere.app`, choose **Open**, then **Open** again.
2. Or open **System Settings → Privacy & Security** and choose **Open Anyway**.
3. If macOS reports the app is damaged:

```sh
xattr -dr com.apple.quarantine /Applications/Elsewhere.app
```

Verify the download:

```sh
shasum -a 256 -c Elsewhere_0.1.0_universal.dmg.sha256
```

## Known limitations

- No Apple signing, notarization, or auto-update.
- No cloud sync, accounts, collaboration, or version history beyond the current undo stack.
- World size is fixed at 1100 × 680; nodes cannot be rotated; only Place and Category resize.
- Image nodes are placeholders; image upload is not implemented yet.
- English interface only.
