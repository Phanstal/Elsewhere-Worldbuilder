# Elsewhere v0.1.4

A new app icon.

## What's changed

- **New application icon.** The mark is now a warm ivory squircle, a thin grey ring, and a larger italic serif `E`. The old icon used a smaller ring and letter with more empty margin.
- **Regenerated the full icon set.** `icon.icns` (macOS), `icon.ico` (Windows), the PNG sizes used by the macOS bundle, and the iOS / Android sets all come from the same 1024px source at [`docs/design/icon-source.png`](https://github.com/Phanstal/Elsewhere-Worldbuilder/blob/main/docs/design/icon-source.png).
- **No functional changes.** The window-dragging fix from [v0.1.3](https://github.com/Phanstal/Elsewhere-Worldbuilder/releases/tag/v0.1.3) is included.

## Install

Download `Elsewhere_0.1.4_universal.dmg` (Apple Silicon and Intel, macOS 12+) and drag `Elsewhere.app` to `/Applications`.

This build is **unsigned and not notarized**. On first launch:

1. Right-click `Elsewhere.app`, choose **Open**, then **Open** again.
2. Or open **System Settings → Privacy & Security** and choose **Open Anyway**.
3. If macOS reports the app is damaged:

```sh
xattr -dr com.apple.quarantine /Applications/Elsewhere.app
```

Verify the download:

```sh
shasum -a 256 -c Elsewhere_0.1.4_universal.dmg.sha256
```

SHA-256:

```text
PENDING-DMG
PENDING-ZIP
```

Sizes: DMG PENDING bytes; ZIP PENDING bytes. The same values are published in `SHA256SUMS.txt`.

## Known limitations

- No Apple signing, notarization, or auto-update.
- No cloud sync, accounts, collaboration, or version history beyond the current undo stack.
- World time is limited to 3 snapshots; there is no merge or diff between moments.
- World size is fixed at 1100 × 680; nodes cannot be rotated; only Space (and legacy Place / Category) resize.
- Images are stored inline in the world file; there is no crop, frame, or media library yet.
- English interface only.
