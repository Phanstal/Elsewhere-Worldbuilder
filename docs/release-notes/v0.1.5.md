# Elsewhere v0.1.5

Canvas interactions from Figma Make Versions 34 and 35.

## What's changed

### Canvas zoom

- **Zoom no longer re-renders the React tree every frame.** A `requestAnimationFrame` loop writes the world transform directly to `translate3d(...) scale(...)`; the final view and toolbar percentage sync once when the animation settles.
- **Pinch / Ctrl + wheel zooms at the pointer** with softer damping, a 0.4–1.8 range, and one shared animation target for repeated wheel input.
- **Two-finger trackpad scrolling pans the canvas.** Panning commits to React after a short idle, then autosaves.
- Context-menu creation, image drops, and relation previews use the live zoom/pan values while an animation is in flight.
- Starting any canvas drag safely stops the active zoom animation first.
- The world layer gets a GPU compositing hint so transform-only frames stay off the layout path.

### Selection, layers and clipboard

- **Marquee selection.** Drag blank canvas to draw a selection box and multi-select nodes. Selected nodes stay selected and drag together as one group with a single undo step.
- **Right-click a node** for Bring forward / Send backward / Bring to front / Send to back. The `layer` value is stored in the world and survives reloads and `.elsew` round trips.
- **Cmd / Ctrl + C / V** copies and pastes the current selection, offset by 32px, with fresh IDs and remapped parent references.
- **Description saves on blur or outside click.** The textarea keeps a focus/blur transaction, so the description edit is one undo step even when another node is clicked before the blur handler runs.
- **All Elements sits above Create** in the sidebar; the Search World field is gone.
- **Space nodes render at 80% opacity** so they read as backdrops instead of cards.
- The inspector shows the multi-selection count and offers a group delete.

## Install

Download `Elsewhere_0.1.5_universal.dmg` (Apple Silicon and Intel, macOS 12+) and drag `Elsewhere.app` to `/Applications`.

This build is **unsigned and not notarized**. On first launch:

1. Right-click `Elsewhere.app`, choose **Open**, then **Open** again.
2. Or open **System Settings → Privacy & Security** and choose **Open Anyway**.
3. If macOS reports the app is damaged:

```sh
xattr -dr com.apple.quarantine /Applications/Elsewhere.app
```

Verify the download:

```sh
shasum -a 256 -c Elsewhere_0.1.5_universal.dmg.sha256
```

The same hashes are published in `SHA256SUMS.txt` and attached to the GitHub release.

## Known limitations

- No Apple signing, notarization, or auto-update.
- No cloud sync, accounts, collaboration, or version history beyond the current undo stack.
- World time is limited to 3 snapshots; there is no merge or diff between moments.
- World size is fixed at 1100 × 680; nodes cannot be rotated; only Space (and legacy Place / Category) resize.
- Images are stored inline in the world file; there is no crop, frame, or media library yet.
- English interface only.

The full acceptance checklist is in [docs/acceptance.md](https://github.com/Phanstal/Elsewhere-Worldbuilder/blob/main/docs/acceptance.md).
